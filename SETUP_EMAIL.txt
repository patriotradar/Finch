Aegis email configuration

Use a dedicated business mailbox. Store credentials only as protected deployment
environment variables:

FINCH_EMAIL
FINCH_EMAIL_PASSWORD
FINCH_SMTP_HOST
FINCH_SMTP_PORT
FINCH_IMAP_HOST
FINCH_IMAP_PORT

Preserve the existing working SMTP values. Never commit credentials to this
repository. After configuring a private preview, use the owner dashboard's
connection test, send a message to an address you control, verify delivery and
reply handling, then check that the activity log records the event.

Every outreach message must include the one-click opt-out URL generated from
FINCH_OPTOUT_SECRET. Suppression is permanent unless the recipient explicitly
requests otherwise.
